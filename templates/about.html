About This Project

Student Wellness Tracker is a web application designed to help college students keep an eye on their health and daily lifestyle habits.

College life can be busy and stressful. Students often forget to sleep well, drink enough water, exercise or take care of their mental health. This project aims to make tracking these habits simple.

Technologies Used

  • HTML and CSS for the design
  • JavaScript for interactivity
  • Python Flask for the backend
  • MySQL for storing data (coming later)
